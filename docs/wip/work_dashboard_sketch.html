Work dashboard

The Work view answers how far each activity can move. This sketch shows the same answer as pictures, for an executive reading it in a minute. Every figure is computed from Sandbox 7.0’s master data with the four views’ own rules.

The grid has one column per process group, one card per process, and one square per activity. Click a process to list its activities.

Reading it

Darker navy means more of the work stays with a person. The stacked bars show each group’s mix of stages; the matrix shows how Consequence of Error holds the ceilings down.
