ABC Test Org: a complete data set for PCF 7.0

One worked example of every input the sandbox takes, across all 118 activities of PCF 7.0, so each part of the Work, People, Data and Findings views has something real to show. Each activity carries one scenario; every process group shows each Readiness Gate outcome where it has enough activities. 7.2 Recruit, Source and Select is the hand-written set, with GiGi’s Critical pilot (7.2.3.4); the other groups are generated by rule.

Loading saves the set through the sandbox’s own endpoints, under your sign-in, exactly as if each record were entered by hand. It replaces ABC Test Org’s current data for the chosen scope; every earlier entry stays in its record’s history. Nothing outside the scope is touched.

What’s in the scope

    Every evidence entry and note starts “Test data.”, and every readiness rating carries all six evidence fields; one required action is left out on purpose (7.2.2.4). Generated Nov 17, 2026 from the sandbox’s own model by scripts/build-7.js, so each element grid derives to the stage it records. A full load is about 270 saves and takes a minute or two.

    Scenarios

    What each activity shows once loaded. The outcome is the Readiness Gate for its next step, as Findings’ Readiness dashboard reads it.

    Where each input shows

    • Stage assessment and element grid: Work, the Current State step; open Reassess on any assessed activity. Evidence types and confidence vary across the set.
    • Unassessed: dashed squares in Work and Findings.
    • Element past its own ceiling: red dot in Work; Findings map and Exceptions report.
    • Past the ceiling, no override and ceiling override with a review: Work and the Findings summary.
    • Readiness Gate: Work, the arrow before the next step. Weakest link on High and Critical work, by role below High, governance oversight, required actions, Human Agency narratives per role, and all six evidence fields under every rating.
    • Step evidence: Met, Not met by a rate, Not met by an open Serious entry, Insufficient on volume, sign-off on High work and Automation, discrepancy logs.
    • Findings: the Readiness dashboard shows every gate outcome; “What’s holding the work” ranks what holds them.
