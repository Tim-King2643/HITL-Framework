Unassessed, not Human-only

Agreed Nov 5 (GR-052, from GiGi’s three-pilot comparison): organization assessments start Unassessed, with no predetermined stage. An organization with no assessment no longer inherits a Human-only Current State as if it had been observed.

Today the sandbox counts every activity an organization has not assessed as Human-only, at 95% H. Human-only stays the Reference Model’s baseline; it stops standing in for an organization’s Current State.

Assessed activities are simulated one step below their ceiling, so the example has something to show. In the sandbox they come from the organization’s saved assessments.

The rules, recommended
  1. An activity is Unassessed until its organization saves an assessment. It shows as Unassessed, with a dashed square, and no step of its ramp is marked reached.
  2. Current % H and the stage mix count assessed activities only, always with their coverage (“Assessed 12 of 118”). With nothing assessed, Current State shows no figure.
  3. Findings that read the Current State (past the ceiling, element past its ceiling) cover assessed activities only; coverage is reported beside them, never as a finding.
  4. Where an analysis needs a stage for an Unassessed activity (control points, checked inputs), it uses the Reference Model at the ceiling, labeled Modeled, as the views already do for the reference.
  5. The Reference Model itself is unchanged: its views still show Human-only as the starting baseline.
