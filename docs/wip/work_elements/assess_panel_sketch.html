The panel that opens from an activity card while ABC Test Org is selected. The assessor sets who leads each work element and records the evidence for it. The working relationship is derived from the grid.

It opens on the activity clicked in the four-view sketch, with the same element ceilings. ABC Test Org starts from either the Reference Model (nothing assessed) or the generated test assessment. Save assessment keeps your assessment in this browser on top of that start, and the four-view sketch shows it; the real build saves through the Worker.

An activity nobody has assessed starts with every element at Human and no evidence: the Human-only baseline. Anything above Human is a choice the assessor makes and backs with evidence. Each element’s ceiling, its object phrase and the ◆ control element come from the reference model.

Derivation
  • All elements Human: Human-only.
  • AI only in Research or Evaluate: Judgment.
  • AI assists in Draft, Verify or Communicate, the person leads: Augmentation.
  • AI leads Draft, a person holds the ◆ control element: Oversight.
  • Control element AI-led: Agent-delegation.
  • Control element AI: Automation.
  • Produce / Execute alone doesn't move the stage.
