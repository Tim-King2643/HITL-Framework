How the proposal works

The control element (Decide, or Verify where there is no Decide) is held by today’s ceiling: Human up to Oversight, AI-led at Agent-delegation. An element a factor holds is capped by the ceiling: at Judgment, Evaluate is Human-led and the rest Human; at Augmentation, Human-led; at Oversight and above, AI-led. Every other element may go to AI.

Every activity is assumed to have all seven elements, except 7.2.1.4, whose control element is Verify. The Work Element Reference Data will mark the elements that aren’t part of each activity.
