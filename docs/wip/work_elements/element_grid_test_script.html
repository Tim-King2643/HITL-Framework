Test script · GR-058 acceptance: check the derivation rule in the sandbox’s element grid · GR-058 · Open the sandbox

Element grid and derivation rule

Each case sets the work elements of one activity and checks the Current State the grid derives, its warnings and the ceiling override. The expected results come from the rule as approved in GR-058; a Fail means the grid, the rule or the expectation is wrong, so note what you saw.

Set up once
  1. Open the sandbox signed in (Tim or GiGi; others can only view).
  2. In Organization, choose New organization…: name Element Grid Test, tick Test data. A separate test organization keeps ABC Test Org’s assessments as they are.
  3. In Work, choose process group 7.2 and open processes 7.2.1, 7.2.2 and 7.2.3 with their +.
For each case
  1. Click Assess on the activity’s row. If its grid is still open from the case before, change the leads in place.
  2. Set every element as listed; elements listed as Human stay Human.
  3. Check the Derived Current State line and the warnings before saving, then save.
  4. Mark Pass or Fail.
