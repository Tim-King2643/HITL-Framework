Business Rules Catalog

The rules the framework computes with. Each card gives the rule’s definition on the left and a worked example on the right, worked out from Sandbox 7.0’s master data each time the page opens, using the same logic as the four views.

Adopted rules match an approved register decision and are built. Proposed rules are in the sandbox or a sketch but not yet approved.

    Applying it

    The catalog becomes a BUSINESS_RULES table in pcf7.html, beside the other master data, and is added to the Master Data group as a live view, read from the sandbox like the role taxonomy. A rule changes like any master data: its wording in the table and its code in the same push, with a changelog entry the CI check requires. Each rule’s worked example stays computed, so a code change that breaks the rule shows up on its card.
