Description

This value stream comprises one APQC PCF process group: 8.6 Deploy Services/Solutions — spanning 5 Level 3 processes and 36 Level 4 activities.

At the activity level, this value stream's work breaks down as 17 Transaction activities (rules-based processing suited to automation), 11 Knowledge activities (judgment, synthesis, and interpretation-driven work), 6 Document activities (content generation), and 2 Decision activities (judgment-and-authority gates that stay human by design). No Exception-pattern activity exists within this value stream.

At M3 (HITL Design Intent), the value stream's aggregate human-involvement ratio is 48%, down from a 72% undesigned baseline — the steepest AI convergence opportunity of any PCF 8.0 value stream at 24 points.

Design Narrative

Change-to-Deploy is IT Service Manager's second-largest lane in the domain: Accountable for 3 of 5 L3s — deployment strategy (8.6.1), implementation planning (8.6.2), and change deployment control itself (8.6.3) — textbook ITIL Change Management, the role's core mandate. DevOps Engineer holds Accountable for solution implementation (8.6.4), a pure-execution L3 that shifts from governance to hands-on deployment, and IT Support Specialist closes the stream with rollout (8.6.5) — training, communications, and end-user-facing rollout support rather than technical deployment. This value stream carries both PCF 8.0's steepest AI-absorption gap (24 points, the domain's largest) and its highest concentration of Transaction-pattern work (17 of 36 activities), reflecting how much of change/release management is procedural once the deployment decision itself is made. Its steepest single-activity gap sits in 8.6.1.3 (Define and create deployment procedure workflow, Document-pattern, -32 points).

Handoff Points

The stream opens with IT Service Manager on deployment strategy, implementation planning, and deployment control (8.6.1–8.6.3) — the ITIL Change Management governance layer.

It then hands to DevOps Engineer for pure execution — implementing the technology solution itself (8.6.4) — before closing with IT Support Specialist on rollout (8.6.5): training, communications, and end-user-facing support distinct from the technical deployment.
