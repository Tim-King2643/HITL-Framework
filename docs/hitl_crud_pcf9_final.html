This page maps every data entity each process Creates, Reads, Updates, or Deletes, and the system of record it lives in, for all of 9.0 (Manage Financial Resources) — 11 process groups, 47 Level 3 processes, and 206 Level 4 activities in total. CRUD assignment in this framework is confirmed at L3 process granularity and inherited by L4 children, the same convention already used for RACI — never assigned independently per L4. Coverage is real, not exhaustive: only L3s with a confirmed CRUD assignment show entries; the rest show “·”, an honest gap rather than an inferred one. 47 of 47 L3 processes have confirmed CRUD data so far.
